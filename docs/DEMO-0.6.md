# 0.6：报告建议的离线演示版

这版把报告里尚未实现的八项功能各做了一条能走通的流程，方便实际体验后决定继续打磨哪里。它是可运行的 Demo，不是把 Word 报告里的全部产品能力都做完了。0.5 的本地棋局库仍可使用。

## 从哪里打开

完整解压 `artifacts/anxin-xiangqi-windows-0.6.0.zip`，运行 `anxin_xiangqi.exe`。在棋桌工具里点 **练习与研究**；电脑正在思考时，等它落子再进入。练习区会带入当前实盘的副本，实际棋局保持原样。

| 功能 | 这版可以做什么 | 当前范围 |
| --- | --- | --- |
| 原创残局 | 选择题目，在棋盘走出一步使对方无棋可走；可看提示、重做 | 3 个手工编写的小局面，包含换边、执黑；其中两题是镜像练习。接受所有达到目标的合法走法，不是只有一个指定答案 |
| 战术练习 | 炮架吃子、马跳日吃子、先应将再吃子；答错保持原盘，可以继续想 | 3 个一步场景，不计时、不扣分；进度自动保存，做错的题进入“错题再练”，练对后移出 |
| 声音辅助 | 设置里分别开启提示音和语音；可先试听。落子、吃子、将军使用三种原创合成短音，语音说出走棋和吃子 | Windows 本机 SAPI 中文语音，不联网、不下载声音。声音默认关闭；没有中文语音或播放失败时提示，棋仍可下。新报棋打断旧报棋；不是语音控制或完整读屏适配 |
| 简洁复盘 | 点“简洁复盘”，首末步、前后步、点记录跳转；中文说明吃子、将军和无棋可走 | 根据实际棋盘说明事实，并给简单观察提醒；没有胜率曲线、失误排名或引擎分数，也没有声称每步都是最佳着法 |
| 摆棋 | 选红黑棋子或擦除，点棋盘放置；可用标准摆法、只留将帅，选先走方，再开始试走 | 检查棋子数量、将帅、仕相位置、兵卒范围及将帅照面等；不证明这个局面一定能从标准开局走到。可以手动试走两边并请求电脑建议，不自动变成人机残局赛 |
| 分支试走 | 退回任意已有节点后另走，原路线保留；当前节点的“路线”按钮可切换后续；重复走同一着会进入已有分支 | 一份研究最多 512 个着法节点；“保存研究”保留所有分支和当前位置，演示版只有一个保存位置，替换前可取消 |
| 棋谱导入 | 粘贴本项目导出的完整研究、局面文字或坐标着法；导入前检查完整内容，通过后才换研究棋盘 | 支持 `a3a4 a6a5` 这种 ICCS 坐标序列，以及带起始 FEN 头的有限文字格式；支持完整研究 JSON 的分支往返。不是完整 PGN 兼容，没有 XQF、中文着法、数字着法、注释和其他软件分支语法 |
| 互动教程 | 七类棋子各有一题，先读说明，再自己选子落点；错误可重试，成功说明走法要点 | 7 个原创一步任务，是入门教学演示；尚未包括多步引导、开局课程和自动识别学习难点 |

## 建议这样试一遍

1. 点“互动教程”，选“兵：向前不过退”。先走别的兵，看看错误提示和错题列表，再按题目走最左边的红兵。没有扣分，也没有倒计时。
2. 点“原创残局”，体验“双车封住宫门”。可以点“看提示”，完成后点“再做一次”。无棋可走也算负，包括困毙；本版规则不要求必须吃掉将帅才结束。
3. 点“摆棋”，再点“标准摆法”和“开始试走”。手动走红黑双方，回退一步，另走一着；再次回退后就能在两条路线之间切换。
4. 点“保存研究”，退出练习区再进入，点“继续研究”。题目进度会自动保存，但自由试走须主动保存；未保存就离开的试走不会恢复。
5. 点“导出棋谱”。“复制完整研究”包括所有分支，“复制当前路线”只包括这一条路线；粘贴到记事本保存。再通过“导入棋谱”粘贴回来，检查局面和路线。试试粘贴 `a3a9`，错误内容应被拒绝，当前研究保持原样。
6. 返回棋桌，打开“使用设置”，先“试听声音”和“试听报棋”，再决定开启哪项。系统静音、输出设备和是否安装中文语音都会影响实际听到的效果。

导入坐标的简单例子：

```text
a3a4 a6a5 b2e2
```

界面不要求用户理解 FEN；“局面文字”是给已有棋谱的用户准备的可选输入。标准开局的棋谱也可以直接粘贴坐标序列。原来回看中的“复制完整棋谱”是给人阅读的中文说明，不能冒充本版支持导入的坐标格式。

## 数据和安全边界

实盘续局、我的棋局、练习研究是不同的数据范围。练习进度与保存的研究位于应用支持目录 `study-notebook/games.json`，和实盘库 `chess-library/` 分开。复用同一文件存储实现，保留上一份成功写入的备份，发现外部修改后拒绝覆盖；坏档不静默改成空记录。存储失败时棋盘保留，可以重试或导出。

导入文字和整个练习记录各限制为 256×1024 个 UTF-16 代码单元；最多 512 个试走节点。复杂棋谱、较长实盘超出范围时，仍可使用原棋桌的回看；Demo 不会截断原谱或覆盖实盘。这些限制不是“支持所有棋谱”的声明。

题目、提示文字、界面逻辑和合成提示音是本项目自有实现。此前 REA 静态研究只用来理解功能与流程，没有把原 APK 的代码、美术、声音、模型或服务器接口加入应用。运行游戏仍不需要 REA。

实际测试、构建和未验证项目见 [验证记录](VALIDATION.md)。Android 方向仍暂停；这次交付的是 Windows Demo。
