# 安心象棋 v0.3.0 · Windows 离线试用版

面向长辈的开源离线象棋，使用本地 Pikafish + NNUE 陪练，无需账号或联网。

## 下载与使用

- **普通用户下载 `anxin-xiangqi-windows-0.3.0.zip`**。完整解压后，双击 `anxin_xiangqi.exe`；保留旁边的 DLL 和 `data` 文件夹，不要直接在压缩包里运行。
- `anxin-xiangqi-source-0.3.0.zip` 为完整对应源码，含固定版本的引擎源码、同一 NNUE、许可和构建说明。Windows 便携包内也附有该源码包。
- `SHA256SUMS.txt` 提供两个压缩包的 SHA-256，可用 PowerShell `Get-FileHash 文件名 -Algorithm SHA256` 核对。

本次发布 Windows x64 版本。Android 工作暂缓，未提供 v0.3.0 APK。

## 本版改进

- 三档文字大小继续跟随系统字号，设置自动保存。
- 可选落子前确认，预览落子后的棋盘；取消不走棋。
- 可对弈的放大棋盘，棋格至少 60 逻辑像素，支持双向滚动。
- Windows 侧栏独立滚动，增加减少动效选项。
- 保留五档本地 AI、执红/执黑、提示、悔棋、翻转、回看及自动续局。长将长捉由固定版本 Pikafish 识别并要求违规方变着。

## 验证与限制

35 项回归测试通过，包含真实 Windows 引擎/NNUE。最终桌面调整后，10 项界面测试及 Windows 模式预览测试通过；Windows Release 构建与启动检查通过。构建环境为 Flutter 3.47.7 / Dart 3.13.5、Visual Studio 2022，原生引擎使用 MinGW-w64 GCC 14.2.0。

这是离线试用版，尚未完成干净系统、完整人工对局、Narrator / 键盘、实际系统 DPI 缩放和长辈试用验收。残局练习、棋谱导出、声音/语音仍待实现。没有将 AI 难度映射到腾讯段位，也未宣称与所有竞赛规则完全一致。
