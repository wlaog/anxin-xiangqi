# 安心象棋 v0.6.0 · Windows 离线练习 Demo

本次将报告建议的八项能力做成可操作的离线演示，同时包含 0.4 的中文棋谱与键盘操作、0.5 的本地多盘棋局库。无账号、广告、付费或遥测，运行不需要联网或 REA。

## 下载与使用

- 普通用户下载 **`anxin-xiangqi-windows-0.6.0.zip`**，完整解压后运行 `anxin_xiangqi.exe`，保留旁边的 DLL 和 `data` 文件夹。
- 棋桌工具里的 **练习与研究** 提供小题、教程、摆棋、试走和导入。实盘保留；自由研究须主动保存。
- **使用设置** 可分别开启提示音和中文语音，默认关闭，建议先试听。语音使用系统已安装的普通话声音。
- `anxin-xiangqi-source-0.6.0.zip` 是完整对应源码，包含固定引擎源码、同一 NNUE、许可和构建说明；Windows 包内也附有这份源码。请勿用缺少子模块及模型的 GitHub 自动 “Source code” 归档替代完整源码包。
- `SHA256SUMS.txt` 提供两个 ZIP 的校验值。

## 本次可以体验

- 原创一步残局 3 题、战术练习 3 题、七类棋子的互动教程 7 题，支持提示、重做、进度保存和错题再练；两道残局为镜像练习。
- 三种原创合成提示音和可选本机中文报棋。
- 中文走棋说明、吃子/将军/终局事实回看，支持前后步和点记录跳转。
- 自由摆棋，开始试走前检查将帅、棋子数量与位置等基本合法性。
- 回退另走保留原分支，切换路线、保存研究和继续研究；覆盖已保存草稿可取消。
- 导入导出本项目完整研究 JSON、局面文字和 ICCS 坐标着法子集；导入失败保留当前研究。
- 本地棋局库可保存、回看、改名、收藏、继续旧盘；新局前和终局自动归档，存储失败保留棋盘。

## 验证与当前范围

101 项回归测试通过，包含真实 Windows Pikafish / NNUE、全部原创题目目标、存储失败和分支往返；静态检查、Windows Release 构建、窄屏及 2.8 倍文字检查通过。已实际启动程序，完成一道残局并返回原实盘，调用了两种声音试听；原生声音 API 请求均被接受，未将其等同于听感验收。

这是 **Demo 预发布**。题目均为一步任务，尚无多步课程；自由研究只有一个保存位置，每份最多 512 个试走节点。复盘暂无胜率、引擎评分或失误诊断。导入不是完整 PGN 兼容，暂不支持 XQF、中文/数字着法及其他软件的注释、分支语法。尚未完成长辈试用、听感、Narrator、干净系统和崩溃恢复验收。本次只发布 Windows x64，Android 工作仍暂停。
