# 第三轮：登录后的网页人机对局

日期：2026-10-15。按用户最新要求优先 Windows，暂停 Android / SDK 工作。本轮观察对象是天天象棋网页版，不能把它的行为直接当作 APK 4.4.6.2 的安装后行为。

## 方法和证据边界

使用独立、可见的 Edge 会话，用户亲自微信扫码。中断后在同一浏览器上下文重新打开网页，登录状态恢复。未复制用户原 Edge 配置、cookies 或登录令牌。

网页由 Cocos canvas 绘制。Playwright 执行已看见的界面坐标点击、截图和公开资源请求；REA 6.5.0 CLI 发现 CDP 目标并被动观察窗口。不能把 Playwright 点击说成 REA 的点击，也不能把被动记录说成覆盖了登录前所有流量。

原始截图含个人头像、战绩或好友内容，只保存在被 Git 忽略的 `research/private/`。公开仓库只提交行为摘要和证据索引。没有操作在线匹配、好友对战、支付、奖励领取或账号设置。

## 安心象棋的设计决定

以下是本项目自己的决定，不是反编译结论：

1. 保留木质棋桌、明确选子/落点、应手和设置入口，继续使用原创纹理与独立代码。
2. 保留五档本地公开引擎，提示和悔棋不设收费额度；不引入在线排名和胜负惩罚。
3. 在默认大字基础上增加两档放大，继续叠加系统字号；走子提示设置自动保存。
4. 增加可选落子确认，用落子后的棋盘预览说明这一步，取消不落子；棋局已变化时旧确认失效。
5. 提供减少动效选项，并尊重系统减少动画设置。
6. 增加独立放大棋盘，保持至少 60 逻辑像素棋格并可继续对弈，支持双向滚动；Windows 侧栏独立滚动。
7. 残局练习、分析解释、棋谱导出、语音和键盘操作后续分别验收；不能把“原版有入口”写成“安心象棋已经实现”。
