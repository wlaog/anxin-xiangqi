# 象棋行为研究

先读项目 `docs/RESEARCH.md`，核对本轮是否有实际样本和需要回答的问题。用户已允许先完成独立离线项目；缺样本时继续开发，不把通用象棋知识写成原版分析结果。

研究范围围绕开局、人机设置、选子落子反馈、悔棋、终局、退出与续局。先建立最小行为问题，再选择 UI 观察、APK 清单或针对性的静态分析。不为重做离线棋桌默认扩大到账号、服务器或付费功能。

REA 的 skill 在工具克隆的 `.agents/skills/reverse-engineer-anything/SKILL.md`；存在时先读相关路由，工具缺失则按官方文档准备或使用 CLI。游戏本身不依赖该路径。先核对 Node、实际发布版 schema 与对应提供者，不把 skill 文件的存在当作 MCP 已连接。

每个发现保留样本 SHA-256、版本、工具版本、问题、证据位置、复验步骤和局限。明确区分静态观察、运行观察、推断与未知。静态引用不能证明分支在运行中执行。

只将可公开的行为规格、摘要和自有实现写入仓库。原 APK、提取素材、反编译代码和设备数据放在忽略目录。设计决定需回到本项目长辈用户的需求，不要求逐像素复制参考产品。
